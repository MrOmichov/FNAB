# Просмотр игры и визуальная проверка

## Задание визуальному тестировщику

Передать `visual_tester` затронутые сцены, нужные состояния, ожидаемый вид и
эталоны ниже. Если роль не доступна в инструментах текущего сеанса, передать
то же задание `tester`. Наличие `.codex/agents/visual_tester.toml` само по себе
не подтверждает доступность роли в уже открытом сеансе.

Один агент управляет окном; остальные используют его результаты. Проверять
только затронутые состояния и необходимые переходы, повторять проверку после
новых изменений или при неполном доказательстве. Не читать всё дерево ассетов.
Для каждой находки: важность, состояние, ожидание, наблюдение, кадр и шаги
воспроизведения; отделять дефект от вопроса дизайна. Завершать кратким списком
проверенных и непроверенных состояний. Пустые разделы и полные логи не нужны.
Находки автоматически не исправлять.

## Проверенный способ (2026-10-07)

**VERIFIED:** Godot 4.4.1 запускается вне песочницы Codex. Через навык
`computer-use:computer-use` (`@oai/sky` в `node_repl`) получены снимки меню
и экрана INTRO ночи 1; нажатие «Новая игра» выполнило переход в Night.
Полный игровой плейтест этим не подтверждён.

Команда запуска из PowerShell:

```powershell
& 'C:\Godot_v4.4.1\Godot_v4.4.1-stable_win64.exe' --path 'C:\Users\Persik PC\Documents\Projects\Godot\FNAB'
```

При запуске из Codex использовать разрешённый запуск вне песочницы, если
в песочнице воспроизводится `CrashHandlerException: Program crashed with signal 11`.
**UNKNOWN:** точная причина падения. Оно воспроизводилось также с `--headless`
и с `--rendering-method gl_compatibility`; это не доказательство ошибки игры.

Для снимков и ввода читать актуальный навык Computer Use. Получить реальные
окна через `sky.list_windows()`, выбрать единственное окно `FNAB (DEBUG)`,
активировать его и вызвать `sky.get_window_state({window})`. Проверенный снимок
до активации включал перекрывающее окно: для чистого кадра нужна активация игры.
Координаты и screenshotId использовать только из последнего снимка; после
каждого действия получать новый снимок. Инструмент показывает кадр прямо в чате.
Настройки проекта и игровой код для этого менять не требуется.

## Визуальные эталоны

- `assets/Ремейк игры/камера/комнаты/главный зал/итог.jpg` — сведённый вид;
  изображение просмотрено. Персонажи на эталоне не задают runtime-расстановку.
- `assets/Ремейк игры/камера/комнаты/коридор/итог.png` — найденный сведённый вид.
- `assets/Ремейк игры/камера/комнаты/сцена/готово.kra`
- `assets/Ремейк игры/камера/комнаты/офис/офис.kra`
- `assets/Ремейк игры/камера/комнаты/комната с псом/комната с псом.kra`

Файлы `.kra` — исходники Krita. Их содержимое пока не проверено визуально.
Эталоны служат для сравнения композиции, масштаба и порядка слоёв; не менять
по ним правила AI или состояние персонажей без отдельного требования.
